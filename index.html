Install (30 seconds)

  1. Download the ZIP above, then unzip it anywhere.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode (top-right toggle).
  4. Click Load unpacked and select the unzipped folder.

That's it — click the toolbar icon to open the tool. This manual install doesn't auto-update; the README covers an optional script for that if you want it.

Why an extension?

No proxy needed. A page-hosted version of this tool has to bounce blocked requests through a public CORS-unlocking proxy — which some hosts block outright. An extension with host permissions fetches cross-origin directly, no proxy, no blind spots.
Nothing leaves your machine. No proxy service ever sees a URL you're downloading.
Not on the Chrome Web Store — distributed straight from GitHub Releases instead.
Source on GitHub — everything runs locally, nothing is uploaded anywhere.
